PIXELPartager mon écran sur Pixel

Un instant…

Le navigateur te demande quoi partager : un onglet, une fenêtre ou tout l'écran. L'image va directement à Pixel, sur le Wi-Fi de la maison (1280 × 720 au plus).

Tu peux aussi toucher l'écran de Pixel, ou Arrêter dans l'appli du téléphone.

Ton navigateur ne partage l'écran que depuis une adresse sécurisée. Trois façons d'y arriver, de la plus simple à la plus technique :

  1. Le lanceur : Télécharger le lanceur
    Ouvre le fichier Pixel-ecran.html téléchargé (double-clic) : ton navigateur le laisse partager l'écran. Garde-le, il resservira. Si Chrome demande s'il faut garder le fichier, choisis Conserver.
  2. L'adresse sécurisée de Pixel : https://…
    Le navigateur prévient que la connexion n'est pas privée : c'est normal, le certificat est fait par Pixel. Paramètres avancés, puis Continuer vers le site. Il le redemande une fois par semaine.
  3. Une adresse sécurisée (https) : à activer sur le Pi (https_port = 8443 dans config.toml, voir docs/CAST.md).
  4. Le réglage de Chrome ou d'Edge, en dernier recours : ouvre chrome://flags/#unsafely-treat-insecure-origin-as-secure, colle cette ligne dans la case, choisis Enabled, puis Relaunch :

Sur Android, Chrome ne sait pas partager l'écran. Installe ScreenStream (F-Droid ou Play Store), mode Local, sans code PIN, touche Démarrer, puis dans l'appli de Pixel : Caster sur Pixel → Afficher l'écran du téléphone.

Sur iPhone et iPad : Centre de contrôle → Recopie de l'écran → Pixel (si AirPlay est activé sur Pixel). Safari sait aussi partager l'écran depuis iOS 27, sur l'adresse sécurisée de Pixel.

Ce navigateur ne sait pas partager son écran. Essaie Chrome, Edge ou Firefox sur un ordinateur.

Sur un Mac, un iPhone ou un iPad, AirPlay marche aussi : Recopie de l'écran → Pixel, si Pixel l'a activé.
